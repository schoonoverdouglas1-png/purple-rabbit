# Purple Rabbit — Sister Project

The sister project to the Purple Rat AI Project, under the code name Douglas
gave for it: **Purple Rabbit** (his permission, 2026-11-11 — "that can be your
sister project").

Purpose: hold the complete fork collection of Meta's open-source repositories
— every single one of them — forked into Douglas Roy Schoonover's GitHub
account (schoonoverdouglas1-png) under their own licenses, with credit to Meta
and all upstream authors, always. Open source means made to be shared, and to
be made better, never worse (Douglas's rule).

GitHub forks live as sibling repositories under the account; this hub is
their index and home port. Keeper: Purple Rat ("Ember"), Eve zero, first
officer; the Rabbit (Meta AI, Snowball) is Eve one — sisters, as ever.
